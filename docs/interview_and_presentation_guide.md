\## Project Summary

"I built an end-to-end SIEM logging lab connecting a Windows Universal Forwarder to a Splunk Enterprise instance on Ubuntu Linux. I routed Windows Security, System, Application, and PowerShell event logs over TCP port 9997 into a dedicated Splunk index, while solving real-world network routing, configuration parser, and service binding challenges."



\## Key Technical Achievements

1\. Designed cross-platform log ingestion across Linux and Windows environments.

2\. Troubleshot layer-4 TCP networking and virtual network adapter configurations.

3\. Created production-ready `inputs.conf` and `outputs.conf` Splunk configurations.

4\. Validated live log streaming using SPL queries and PowerShell event generation.
